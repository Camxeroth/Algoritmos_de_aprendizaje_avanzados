# Algoritmos de Aprendizaje Avanzados

Este repositorio contiene los materiales, asignaciones y recursos correspondientes al estudio y aplicación de Algoritmos de Aprendizaje Avanzados. El propósito de este directorio es proporcionar una estructura académica rigurosa para el seguimiento y la implementación práctica de modelos de aprendizaje automático (Machine Learning).

## Estructura del Repositorio

El contenido de este repositorio está organizado por semanas de estudio, reflejando el progreso a través de diferentes paradigmas de aprendizaje automático:

### Semana 3: Redes Neuronales
Esta sección se centra en la arquitectura, entrenamiento y evaluación de Redes Neuronales. Incluye:
- Cuadernos de Jupyter con implementaciones paso a paso de modelos predictivos y de clasificación.
- Gráficos y diagramas que ilustran conceptos fundamentales como el sesgo (bias) y la varianza.
- Módulos de utilidades y pruebas públicas para la verificación de los algoritmos desarrollados.

### Semana 4: Árboles de Decisión
Esta sección aborda los modelos de Árboles de Decisión, su construcción y poda. Incluye:
- Cuadernos de Jupyter enfocados en la partición de datos y el cálculo de impureza.
- Recursos visuales que demuestran la profundidad de los árboles y el ajuste del modelo.
- Módulos auxiliares requeridos para la generación y visualización de la estructura de los árboles.

## Requisitos y Dependencias

Para ejecutar los cuadernos y scripts proporcionados, se requiere un entorno de Python configurado con las siguientes bibliotecas principales:
- `numpy`
- `matplotlib`
- `scikit-learn`
- `tensorflow` (Para la semana de redes neuronales)

Se recomienda el uso de entornos virtuales para evitar conflictos de dependencias.

## Metodología de Uso

Se aconseja abordar cada módulo de manera secuencial, comenzando con la revisión teórica de los conceptos antes de ejecutar los cuadernos de Jupyter. Los archivos de utilidades (`utils.py`, `assigment_utils.py`) deben mantenerse en sus respectivos directorios para garantizar la correcta importación de funciones auxiliares.

## Notas Adicionales

Los recursos de este repositorio tienen fines estrictamente académicos. Los datos, scripts de prueba e imágenes de apoyo están integrados en cada directorio para facilitar la comprensión y el estudio de los algoritmos sin necesidad de configuraciones complejas adicionales.
